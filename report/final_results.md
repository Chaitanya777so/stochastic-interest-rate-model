# Final Results

## Project Summary

This project analyzes historical Federal Funds Rate data and develops forecasting models using stochastic finance and machine learning techniques.

## Dataset

- Federal Funds Rate historical data
- Time Period: 1954–Present
- Source: Federal Reserve Economic Data (FRED)

## Models Implemented

### Stochastic Models

- Vasicek Model
- CIR Model

### Machine Learning Models

- Linear Regression
- Random Forest Regression

## Dashboard Components

### 1. Historical Interest Rate Trend
Shows the evolution of Federal Funds Rates over time.

### 2. Annual Average Interest Rate
Displays yearly average interest rates.

### 3. Volatility Analysis
Highlights periods of economic uncertainty and market instability.

### 4. Model Comparison (RMSE)
Compares forecasting models using Root Mean Squared Error.

## Key Findings

- Random Forest achieved the lowest RMSE.
- Machine learning models outperformed stochastic models.
- Interest rate volatility increased during major economic events.

## Conclusion

The project successfully combines stochastic finance models and machine learning techniques to analyze and forecast interest rates. Random Forest provided the most accurate predictions among the evaluated models.
