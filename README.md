# Stochastic Interest Rate Modelling and Prediction

## Overview

This project analyzes historical Federal Funds Rate data and develops forecasting models using stochastic finance and machine learning techniques.

## Objectives

- Analyze historical interest-rate behavior
- Estimate Vasicek parameters
- Implement CIR stochastic model
- Develop machine learning forecasting models
- Compare forecasting approaches
- Visualize results in Tableau

## Technologies

- Python
- Pandas
- NumPy
- Scikit-Learn
- PostgreSQL
- SQL
- Tableau
- Git
- GitHub

## Models

### Stochastic Models

- Vasicek Model
- CIR Model

### Machine Learning Models

- Linear Regression
- Random Forest

## Key Findings

- Interest rates exhibit mean-reverting behavior.
- Historical rates strongly influence future rates.
- Random Forest captured nonlinear relationships.
- Stochastic models provide probabilistic forecasts.
